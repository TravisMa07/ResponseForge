## Delivery boundaries

RF-06A independently reviews selective acquisition, artifact-specific provenance/rights metadata, and a bounded Sysmon Event 1 XML adapter before changing scenario decisions or runtime execution. It uses Refs #6. This separation permits review of untrusted input and provenance without obscuring it with five scenario policies or Docker evidence. RF-06B will freeze mappings against inspected source fields, positive/negative/incomplete expectations and actual Shuffle acceptance separately. Only complete scenario acceptance can close #6. Neither downloaded telemetry nor normalized derivatives enter Git in RF-06A; original synthetic XML tests stay offline. No external XML library or dependency change is needed for the bounded no-DTD subset.

Intended RF-06B scenarios remain PowerShell/process, credential-access/process access, task/actor, ransomware-like recorded indicators, and suspicious communication with supported process association. Source labels cannot establish any of these. Process access is not process creation, a task command is not a task-created event, a ransomware note is not encryption, and command text cannot establish a file effect. Narrow explicitly where required. Artifact rights and genuine native executions remain independent gates.

## Frozen RF-06A interfaces

Integration-owned `dataset_contracts.py` defines strict `DatasetArtifact`: `artifact_id` (safe slug), `revision` (40 lowercase hex), `path` (canonical relative ASCII path), `sha256`, `size_bytes` (strict integer 1..1048576), `format='sysmon-xml'`, and `rights: DatasetRights`. Repository is fixed `splunk/attack_data`; arbitrary repositories, URLs, branches, traversal, query/fragment/encoding/backslash and script execution are excluded. Computed `source_url` is the pinned GitHub blob URL; `download_url` is the pinned media.githubusercontent.com LFS URL. Rights has `license_id='Apache-2.0'`, exact `license_sha256`, `reviewed_paths` (nonempty canonical paths to reviewed license/README/metadata), and `review_note` (bounded explicit artifact-specific review, including exceptions/NOTICE findings). Root terms alone are never an automatic rights review. The maintained catalog records the reviewer finding; these fields are review evidence, not a legal clearance or mechanism for treating arbitrary manifests as trusted operator configuration. License acquisition uses exact pinned raw.githubusercontent.com /LICENSE bytes and SHA.

`ReplayOrigin` has `source='splunk-attack-data'`, `source_ref` (pinned blob URL), `transformation='sysmon-event1-v1'`. `ReplayBatch.origin:ReplayOrigin|None` defaults None for unchanged original fixture compatibility. Batch SHA remains the original raw source-byte SHA. `make_alerts` and evidence provenance use this origin when present; original synthetic defaults remain unchanged. Recorded alerts explicitly use recorded source labels, and original record IDs/times remain unchanged. No downloaded record passes through a synthetic provenance label.

Acquisition writer owns only `src/responseforge/datasets.py`. `fetch_artifact(artifact:DatasetArtifact,directory:Path,*,opt_in:bool=False,transport:httpx.BaseTransport|None=None)->Path` requires explicit True before filesystem/network work; revalidates detached manifest, uses bounded streamed HTTPS with TLS verification, no redirects/proxies/environment credentials/retries, fixed timeouts, status200 only, identity encoding, exact size/hash and verified license bytes. A request may fetch only the pinned LICENSE and selected artifact. Atomic publication requires Darwin renamex_np/RENAME_EXCL or Linux renameat2/RENAME_NOREPLACE; unsupported platforms/filesystems fail closed without an overwrite fallback. Output is a private new artifact directory containing `source.xml`, `LICENSE`, and canonical `manifest.json`; no overwrite, symlink traversal or partial published artifact on failure. Existing verified complete bundles can be reused offline; conflicts reject. Unknown acknowledgment is not retried automatically. Error messages omit source bytes, URLs and private paths.

Normalization writer owns only `src/responseforge/replay/sysmon.py`. `normalize_sysmon(raw:bytes,*,artifact:DatasetArtifact,scenario_id:str)->ReplayBatch` validates detached manifest and exact bytes/hash before parsing, then accepts UTF-8 concatenated `<Event>` XML exports (optional standard Windows event namespace, optional `<Events>` wrapper), at most1MiB/1000 events/16KiB per event. DTD/entity declarations, processing instructions, invalid UTF-8 and structural XML errors refuse the whole source with safe `ReplayError`. Built-in XML entities remain inert text. Reject foreign namespaces and duplicate/ambiguous System or EventData nodes/fields, including nonwhitespace mixed text in structural containers. Invalid individual event schemas and unsupported provider/EventID quarantine with physical start-line and `invalid_schema`; duplicate conflicts use `duplicate_conflict`, identical repeated records count once. Provider must be Microsoft-Windows-Sysmon; EventID must be1. Computer, positive decimal EventRecordID, Channel=Microsoft-Windows-Sysmon/Operational and aware SystemTime are mandatory; optional UtcTime must independently be valid (Sysmon UtcTime's explicitly UTC unzoned representation may be interpreted as UTC only for that field). SystemTime is the event logging time and UtcTime the process-creation time: they may legitimately differ. observed_at uses SystemTime; preserve both original textual values, including precision beyond Python microseconds. Preserve source time, not replay receipt time; no PID, GUID, parent or account is invented.

Map Image→image, CommandLine→command_line, ProcessId→process_id, ProcessGuid→process_guid, ParentProcessId→parent_process_id, ParentProcessGuid→parent_process_guid, ParentImage→parent_image, ParentCommandLine→parent_command_line, User→account, Hashes→hashes. Keep additional system fields `sysmon_event_id`, `original_record_id`, `original_system_time`, `channel`, `provider` and optional `original_utc_time`. This is an explicit field projection; all other raw fields remain in the unchanged hash-bound source artifact, not copied into normalized fields or silently treated as evidence of unsupported behavior. Field size/count constraints remain unchanged. Endpoint ID and hostname both preserve Computer (no connected endpoint implied); event_id preserves EventRecordID. Scenario ID is trusted operator selection, not an upstream ATT&CK label. Identity/dedup uses full endpoint/scenario/event ID; stable order is original time then endpoint/event identity. Source ID is artifact_id, origin is the exact source URL. No Event3/10/11/Security4698 mapping or scenario policy change is included in RF-06A.

Independent expectation writer owns `docs/expectations/rf-06a.md` and `tests/rf06a/**`; no production edits. Freeze design/expectations before substantive implementation, then demonstrate behavioral reds against importable fail-closed scaffolds before writer GO. Source researcher owns only ignored `.local/rf06-source-review/**`. Assign exact freeze SHA to writers; no commits or competing stack tests. A separate read-only reviewer inspects actual source, tests, catalog and evidence after integration. Primary alone operates any future Docker qualification under the existing reviewed grant.
