## Shared replay types (integration writer)

`responseforge.replay_contracts` contains frozen Pydantic models with forbidden extras; use RF-01 Id/UtcDateTime and strict booleans/integers. `RecordedEvent(event_id: Id, scenario_id: Id, endpoint: EndpointRef, observed_at: UtcDateTime, artifact: Literal[process,network,file,persistence], fields: dict[str,str])`; at most 32 fields, key<=128 chars/value<=4096 chars, strict strings, no execution. Fields retain original source values; reports do not dump them. Revalidate and detach models at untrusted boundaries rather than trusting frozen nested dictionaries. `QuarantineItem(line: int>=1, code: invalid_json|invalid_schema|duplicate_conflict)` contains no raw input or exception text. `ReplayBatch(source_id: Id, sha256: 64 lowercase hex, events: tuple[RecordedEvent,...], quarantine: tuple[QuarantineItem,...], duplicates: int>=0)`.

`ReplayError(ValueError)` in replay module is a safe constant error. `logical_receipt(batch)->datetime` is max observed time+1 second (empty batch error). This is an explicit simulated replay clock, not real remote collection. Stable alert/evidence/proposal identities incorporate dataset hash and scope; changed file bytes are a distinct dataset, never silently substituted. Source event time and logical replay receipt remain separate from core server acceptance/ready timestamps.

## Replay/evidence interfaces (replay writer)

Own only `src/responseforge/replay/**`, `src/responseforge/investigation/**`, and `datasets/fixtures/**`. Shared types are outside these paths. Exclude core/API/storage/contracts/reports/driver/locks/docs/tests. Exports from `responseforge.replay`:

- `load_replay(path: str|Path, *, source_id: str)->ReplayBatch`. Local JSON arrays (.json) and JSONL (.jsonl), no download. Cap bytes at 1MiB, records at 1000, JSONL line at 16KiB; resource/format refusal fails safely rather than silent truncation. Hash exact original bytes. Reject missing/naive/numeric times, unexpected record keys and invalid fields to quarantine with 1-based JSONL physical line or JSON-array record position. Malformed whole JSON gets invalid_json with decode line. Blank JSONL lines ignored. Duplicate identity `(scenario_id, full endpoint identity, event_id)`: identical record increments duplicates and is emitted once; conflicting duplicate quarantined (first valid wins). Stable sort `(observed_at,scenario_id,endpoint_id,event_id,original_position)`. Quarantine never includes source content/exception messages; do not execute/decode commands.
- `logical_receipt(batch: ReplayBatch)->datetime`.
- `make_alerts(batch: ReplayBatch, *, ingested_at: datetime)->tuple[Alert,...]`: one alert per scenario/full endpoint group. Rule `RF-REPLAY-ENCODED-PS` (high) when a process has image basename powershell.exe and command_line case-insensitively contains both `-encodedcommand` and `-windowstyle hidden`. This is a transparent toy rule over observed strings, not a general detector or dataset-label inference. Otherwise `RF-REPLAY-OBSERVATION` (low). Choose earliest matching process as anchor, otherwise earliest event. Source='replay-fixture', mode=replay. Alert ID is `replay-`+SHA256(canonical JSON [source_id,sha256,scenario_id,endpoint.model_dump(mode='json')]); provenance source='synthetic-fixture', source_ref='fixture:'+source_id, hash exact file and original_event_ids all group IDs ordered. evidence_refs empty until collection. Use supplied aware ingestion time normalized to UTC. All input models revalidated/detached.
- `ReplaySource(batch, *, ingested_at:datetime, speed:float=0, sleep:Callable[[float],Awaitable[None]]=asyncio.sleep)` satisfies AlertSource. Emits make_alerts sorted original anchor time then ID; speed finite>=0, zero no sleeping, positive sleeps nonnegative alert-time delta/speed. Raw records are deterministically ordered; pacing applies to generated alert groups. No VM/network.

`responseforge.investigation.ReplayEvidenceProvider(batch: ReplayBatch, *, clock:Callable[[],datetime]|None=None)` satisfies EvidenceProvider. Captures detached snapshot and rejects live requests/incidents. `list_evidence(incident)` requires exact scenario, canonical endpoint and generated alert ID; bounds recorded events to ±5 minutes around alert anchor. `collect(request)` revalidates CollectionRequest, requires known scenario/full endpoint, artifact allowlist and ordered <=24h window, returns only matching recorded events inclusively. Unknown scope rejects; known scope with no matching artifact yields one unavailable Evidence (observed_at/provenance=None, explicit generic reason) and gap. Available evidence has exact source hash/ref/original ID/time, sensitive classification, and current replay-provider clock for collected_at. Stable evidence ID `evidence-`+SHA256(canonical JSON [source_id,sha256,incident_id,scenario_id,endpoint.model_dump(mode='json'),event_id]); missing IDs additionally include artifact/start/end. No fabricated parent/process/network artifacts. `list_evidence` uses all recorded artifacts in its bounded window; missing parent_guid reference is reported by integration as a known gap, not a synthetic parent record.

Fixtures: original synthetic suspicious (encoded hidden PowerShell with process_id='42', process_guid and missing parent reference), benign (ordinary PowerShell command), incomplete (same signal but missing process_id). Endpoint IDs unique per fixture; source timestamps explicit; hostile command strings remain inert. Add manifest.json describing source_id/path/hash/origin='original-synthetic', fields, expected rule/missing evidence and redistribution note ('project license unselected; no third-party corpus'). The independent test oracle is the frozen matrix below, not manifest outputs generated from implementation.

## Stateful mock provider (mock writer)

Own only `src/responseforge/integrations/mock_edr/**`. No core store schema changes: provider owns a separate local SQLite file containing simulated endpoint state and action/effect log. Same application/package and SQLite technology; never contacts an endpoint or runs commands. `MockError(ValueError)`; `MockResponseProvider(path: str|Path, *, clock:Callable[[],datetime]|None=None, fault: Literal[none,fail_before_effect,error_after_effect,timeout_after_effect]='none')`, name='mock-edr', version='1.0'. Async protocols exactly RF-01. Constructor refuses foreign/future DB, initializes its own app identity/version, busy timeout/FULL and short atomic transactions; state/effect receipt survive new provider instances.

`seed_endpoint(endpoint:EndpointRef, *, processes:tuple[str,...]=(), isolated:bool=False)->None` seeds canonical replay endpoint and allowlisted `process:<id>`, `host:<endpoint_id>` and `marker:demo` resources. Repeating identical initial seed never resets current effects; changed canonical identity or initial seed conflicts. `snapshot(endpoint:EndpointRef)->dict[str,Any]` returns detached `{endpoint_id, isolated:bool, running_processes:list[str], markers:list[str], effect_count:int}`. Capabilities only for exact seeded endpoint, actions terminate_process/isolate_host/unisolate_host/test_marker in replay mode. Never advertise unsupported quarantine/block/persistence or live isolation.

`execute(ApprovedAction)` revalidates full models/snapshot/approved decision/current positive TTL on NEW delivery, mode=replay, seeded endpoint/resource/action. All model copies and nested dictionaries are untrusted; no arbitrary process/shell calls. Durable idempotency key binds full proposal snapshot; identical retry returns original receipt even after expiry, changed scope/key reuse rejects. Store effect and receipt in one transaction before any injected post-effect exception/timeout. Deterministic `exec-<proposal_id>`, provider/mode/case correlation; dispatch acknowledged + verification pending, simulated=True/verified_live=False. Count actual simulated state transitions separately from deliveries (no-op doesn't increase effects). fail_before_effect persists failed receipt/error and no effect. error_after_effect commits then raises sanitized MockError; timeout_after_effect commits then awaits outside transaction, allowing core cancellation. Duplicate lookup never reinjects fault or applies effect twice.

`verify(execution)` revalidates/binds exact execution/proposal/case/provider/mode to original receipt. No original receipt gives pending, not fabricated success; conflicting receipt rejects. Verify desired simulated state against durable effect/endpoint state; failed dispatch verifies failed. checked_at=server clock for terminal results, all simulated=True/verified_live=False. unisolate_host is a distinct approved rollback action; it is never automatically applied after failure. Provider construction alone is not approval authority: core still authenticates and authorizes every dispatch.

## Offline driver, API and report (integration writer)

`responseforge.replay_driver.run_replay(batch:ReplayBatch, *, database_path:str|Path, mock_path:str|Path, output_dir:str|Path, decision:Literal[none,approve,reject]='none', speed:float=0, clock:Callable[[],datetime]|None=None)->ReplayRunSummary` is async. Summary fields incident_ids:tuple[str,...], report_paths:tuple[str,...], quarantine:tuple[QuarantineItem,...], duplicates:int, simulated:Literal[True]=True, verified_live:Literal[False]=False. Make explicit replay Settings with canonical batch endpoints, independent randomly generated role credentials and stable actor identities, replay source allowlist and narrow observed resources. Mock seed only observed process IDs; no invented running processes. Register provider name/version and ReplayEvidenceProvider explicitly. HTTPX ASGITransport exercises authenticated API without opening a TCP listener. HTTPX becomes exact-pinned runtime dependency. No Shuffle callback/emulation is called a real workflow.

Run normalized alerts through API, triage/investigate, collect bounded recorded evidence, propose terminate_process only for a signal with a valid recorded process_id and GUID. Missing target identity or benign observation records explicit no-action reason and resolves. Include missing parent and absent network evidence as known gaps; never invent lineage. Save available + explicit unavailable evidence. Stable proposal ID derived from alert ID/incident/action/resource, use identical stored proposal on duplicate/resume; do not change expiry or collected_at on repeated delivery. Mark review-ready once source refs, gaps, proposed action/no-action and audit exist. Default leaves proposed action AWAITING_APPROVAL; explicit operator decision approve/reject sends separate approver identity, and approval never comes from telemetry. Approved actions execute through API using registered mock provider. Rejection records no effect and resolves; incomplete/benign case has no proposal. Resume already completed cases without extra effects; unknown execution uses `/reconcile`, never force resend. Failed HTTP operations stop with safe error; do not silently report full success. Repeated evidence collection retains first durable collected_at when all source/scope fields agree.

Integration adds authenticated `POST /v1/incidents/{id}/collect` (CollectionRequest→CollectionResult) with Settings.evidence_provider default None, no live fallback; validates full case/scenario/endpoint/mode, revalidates provider results and exact window/artifact provenance before persistence. Bounded results can be checked against the configured replay source snapshot; untrusted provider evidence cannot bypass case scope. Failure may leave explicitly recorded partial evidence; retry safely reuses immutable records.

`responseforge.reports.build_report(service:CaseService, incident_id:str, actor:Principal, *, secrets:tuple[str,...]=())->dict[str,Any]`, `render_html(report:dict[str,Any])->str`, `write_report(report:dict[str,Any], directory:str|Path)->tuple[Path,Path]`. Use a consistent SQLite read snapshot scoped/authorized by core. Report includes schema version, case/status/mode, explicit simulated/verified_live, source alert refs/hash/event IDs, evidence availability/gaps, proposed actions, human decisions, execution/verification, audit and measurement events. No full raw payload dump. Default redact free-text fields (rationale/assessment/detail/errors/gaps), endpoint hostname/agent identity, action resources and actor identities; retain counts, fixed outcomes and provenance integrity references. Recursively remove named command/token/password/secret/auth/env/raw fields and replace configured secrets/Bearer patterns in remaining strings. Reports cannot leak command lines or sensitive evidence by adding a new field. HTML escapes every dynamic value, no script/external resources. JSON and HTML carry identical redacted content and redaction notice. Output paths use sanitized/hashed case identity, never alert-provided filesystem names; write atomically under requested output directory. Authenticated `GET /v1/incidents/{id}/report?format=json|html` uses the same builder with all configured secrets; other formats reject. No custom dashboard.

Extend `python -m responseforge` with `--replay PATH --source-id ID --database PATH --mock-database PATH --output-dir PATH --decision none|approve|reject --speed N`. Replay default decision none; use private .local paths by default, no live config/provider or automatic human approval. Existing server init/config commands remain compatible. Print only sanitized summary including simulation flags/quarantine codes/report paths, not tokens/record contents. Fixed fixture provenance and logical ingestion enable duplicate rerun; core metric timestamps remain real receipt/readiness times. No measured time-savings claim.

## Ownership and qualification

Replay/evidence writer, mock writer, independent test writer (tests/rf03/** only); integration owns all other changes. Each receives exact freeze SHA, frozen imports and tests, exclusions and required handback (files, tested SHA/dirty scope, commands/results/failures, objections). Meaningful behavioral red precedes final validation. Tests cover deterministic ordering/speed, quarantine, exact hashes/event IDs, scope windows, missing data, stateful mock failures/restart/rollback/idempotency, authenticated offline HTTP cases/reports and hostile redaction/HTML/path input. Read-only independent review inspects actual artifacts before claiming qualification. Original fixtures do not pass RF-06 recorded-data acceptance; offline execution is not real SOAR/live proof.

## Reviewed source/report refinements

API collection now requires full stored-alert agreement with the registered replay source before provider I/O, not scenario/endpoint agreement alone. Report projection explicitly permits known safe model fields; auth/env aliases and unknown future values are redacted. Parser decoding treats Python integer-digit guard ValueError as invalid_json. All three review reproductions have independent regressions; the frozen matrix was not weakened. Metric provenance records Git SHA/dirty status only for a verifiable source checkout, otherwise explicitly marks revision unavailable; it is not a benchmark claim.
