# RF-03 independent expectation freeze

Requirements: issue #3, architecture, replay/evidence/security acceptance and RF-01/02 contracts. Defined before implementation. [Owning design](../rf-03-design.md).

| ID | Condition / fault | Required observation and rationale |
| --- | --- | --- |
| R01 | Unsorted aware source times and ties, same source bytes rerun | Stable ordered events/alerts/IDs, exact file SHA and original IDs/time; separate logical receipt |
| R02 | JSONL bad JSON, missing/naive/numeric time, extra field, duplicate/conflicting ID | Quarantine exact row/code without raw content; identical duplicate counted once, no silent drop |
| R03 | JSON-array equivalent input, >byte/line/row bounds, unsupported format/speed | Safe parse or explicit bounded refusal; finite nonnegative speed; no network/download |
| R04 | Two groups and speed0/2 with injected sleep recorder | Same normalized alerts; zero no wait, positive source alert delta/2; no negative sleep |
| R05 | Synthetic observed encoded hidden PowerShell vs ordinary/incomplete record | Rule derived from observed fields; benign low observation/no action, incomplete signal no invented target/process |
| E01 | Collection scenario/endpoint/time/artifact plus exact boundaries | Only matching source-backed rows, correct hash/ref/event time; wrong mode/canonical scope denied |
| E02 | Missing network/parent/file data | Explicit unavailable reason/gap, no synthesized artifact/parent process |
| E03 | Mutable input/model-copy or provider result with wrong case/hash/event/window | Revalidate/detach and reject unsafe substitution before evidence persistence |
| M01 | New seeded endpoint, terminate/isolate/approved unisolate/marker | Only advertised simulated effects occur; explicit simulated=true/verified_live=false |
| M02 | Same delivery concurrently, new provider instance, expiry retry | One durable effect/receipt; changed scope under key rejected; reseed never restores state |
| M03 | Unknown endpoint/resource/unsupported action/live/forged approval | No effect, no fallback and no execution of record strings |
| M04 | Fail before effect, effect then error/timeout | Durable failed or uncertain core state; verify original effect after restart, no duplicate effect |
| M05 | Missing/forged receipt or state inconsistent with requested effect | Pending/denial/failure, never invented verified success |
| M06 | Rollback via distinct approved unisolate | Final isolated=false with separate durable action/audit; no automatic rollback or erased history |
| I01 | Suspicious fixture via authenticated internal HTTP, default no decision | One case with source evidence, explicit gaps, proposed action, audit/ready metrics, AWAITING_APPROVAL; no effect |
| I02 | Operator approve/reject vs benign/incomplete fixture | Approved one verified simulated effect; rejected/benign/incomplete no effect, documented decision and accurate final state |
| I03 | Rerun with recreated application/provider, prior expired proposal or uncertain outcome | Same case/proposal/effect; preserve first receipt/evidence times, reconcile only original result |
| I04 | Report JSON/HTML with source refs, approvals/outcomes and metric correlation | Accurate mode/state, shared redacted content; no claim of real Shuffle/live or analyst savings |
| I05 | Credentials, arbitrary command/env/raw payload/free text, hostile HTML/path identity | Default redaction suppresses sensitive data, HTML escapes, no active content/remote URLs or path escape |
| I06 | Unauthenticated/wrong-scope report/collection, live-to-replay or wrong provider response | Auth/mode/case/provenance checks fail closed; no leaked private case/report |
| I07 | Actual CLI fixture→case→JSON/HTML and duplicate invocation | Offline runnable path; sanitized summary and same durable cases/effects; original fixtures only |

Golden expected fixture facts are set before code: suspicious process_id42 and process_guid with absent parent is actionable only under human approval; ordinary PowerShell is no-action; suspicious record missing process_id remains no-action with known gap. Independent tests may create their own original small fixtures. Red runs must expose missing behavior with a usable harness, not missing imports. Real Shuffle, recorded corpus coverage, VM effects and release metrics remain independent future gates.
